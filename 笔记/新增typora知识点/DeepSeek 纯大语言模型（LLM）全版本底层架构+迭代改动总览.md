# DeepSeek 纯大语言模型（LLM）全版本底层架构+迭代改动总览
所有版本**基础骨架都是标准 Decoder-only Transformer**，迭代路线清晰：
V1（稠密Dense基线）→ V2（MoE+MLA两大底层革新）→ V3（MoE精细化+MTP+无损失负载均衡）→ V3.2（稀疏注意力DSA过渡）→ V4（Hybrid混合注意力+mHC残差重构+百万上下文原生架构）

## 一、DeepSeek V1（初代，2023.11 / 2024.1）
### 底层基础架构
1. **类型：稠密Dense Decoder Transformer（类Llama2架构）**，无MoE，每层FFN全部参数激活
2. 注意力：**GQA分组查询注意力**，标准RoPE位置编码
3. 归一化：RMSNorm；激活函数SwiGLU
4. 上下文原生窗口：4K tokens；无长文本专项优化
5. 规模：7B / 67B 稠密单模型，训练数据2T tokens

### 核心局限&为后续埋下的痛点
- 稠密模型推理成本高，全部参数参与计算，无法做大参数量同时低成本部署
- KV Cache无压缩，长文本显存爆炸，上限仅4K
- 无稀疏专家分工，数学、代码、通用文本能力耦合在一起，专业化弱

### 这一代只做基线搭建，无底层原创创新，改动：从零搭建自研稠密基线

## 二、DeepSeek V2（里程碑式架构跃迁，2024）
### 底层基础架构（两大原创核心模块）
整体仍为Decoder Transformer，但**FFN、Attention两层全部重构**：
1. **FFN层：DeepSeekMoE 细粒度混合专家（行业标志性架构）**
   - 每层FFN = 2个**共享专家**（所有token必激活）+ 160个路由专家
   - 路由规则：每个token Top6路由，合计激活 2+6=8个专家
   - 总参236B，推理仅激活21B，稀疏激活大幅降低训练/推理算力
2. **Attention层：MLA多头潜在注意力（原创，长文本推理基石）**
   - 低秩联合压缩K、V向量维度，而非删减token；KV Cache体积降低93%
   - 支持128K上下文扩窗（YaRN外推），解决稠密模型长文本显存瓶颈
3. 配套基础组件：RMSNorm、SwiGLU、RoPE、GQA基础逻辑保留

### V2对比V1的所有关键改动
1. **FFN从稠密Dense → DeepSeekMoE稀疏专家架构**，解决大参数量推理成本问题
2. **标准GQA升级为MLA潜空间压缩注意力**，KV缓存压缩、长文本推理可行
3. 上下文从原生4K → 原生支持128K（MLA+YaRN外推）
4. 训练数据从2T → 8.1T tokens，Scaling上限大幅提升
5. MoE配套基础路由损失，用来平衡各专家负载（传统辅助损失方案）

## 三、DeepSeek V3（2024.12，MoE精细化全面升级）
### 底层基础架构
继承V2两大核心：**DeepSeekMoE + MLA**，仅做精细化扩容与训练目标重构
1. MoE配置升级：每层1个共享专家 + 256个路由专家；单token Top8路由，激活合计9专家
   - 总参671B，推理激活37B，专家粒度更细，领域分工更强（数学/代码/通用分离）
2. 注意力仍为完整MLA（向量维度压缩路线不变），上下文上限维持128K
3. 新增全局训练模块：**MTP多Token预测**（训练目标层新增分支）
4. 残差、归一化、激活、RoPE全部沿用V2

### V3对比V2核心改动（三层：MoE路由、训练损失、预训练目标）
1. **MoE负载均衡革新：无辅助损失路由策略**
   废除V2依赖额外loss平衡专家的方案，改用动态路由偏置调节，消除平衡损失带来的性能损耗
2. MoE规模扩容：专家数量160→256，单token激活6→8，知识拆分更精细
3. 新增**MTP多Token预测**：训练时一次性预测连续多个token，提升收敛速度、推理生成速度
4. 训练数据8.1T → 14.8T tokens；引入FP8混合精度训练，降低训练显存
5. 工程：DualPipe流水线并行，适配超大MoE分布式训练

### 过渡小版本 V3.2-Exp（实验稀疏注意力原型）
- 底层MoE、MLA主体不变
- 新增**DSA DeepSeek稀疏注意力**（CSA前身）：序列维度token块压缩+Lightning Indexer检索
- 仅作为V4混合注意力的技术验证版，未大规模商用

## 四、DeepSeek V4（2026，架构级重构，百万上下文原生）
### 底层基础架构
保留外层Decoder Transformer、DeepSeekMoE、MTP，但**注意力、残差、训练优化器三层全部重写**，是四代改动最大一代：
1. FFN：DeepSeekMoE小幅优化（Anticipatory路由预判，降低负载波动），总参V4-Pro 1.6T，激活49B
2. Attention：**彻底废弃MLA向量压缩路线，全新Hybrid混合注意力三分支**
   - SWA滑动窗口（近128token全精度，保局部细节）
   - CSA压缩稀疏注意力（中段4:1 token块压缩+Top-k稀疏检索）
   - HCA重度压缩注意力（远期128:1全局摘要稠密注意力）
     核心变化：从**压缩KV向量** → **直接合并精简历史token序列**，百万上下文KV Cache仅为V3的10%
3. 残差连接：替换传统残差为**mHC流形约束超连接**，解决百万长序列深层数值震荡
4. 优化器：废除AdamW，全模型主模块使用Muon优化器，万亿参数训练更稳定、收敛更快
5. 上下文原生1M tokens，分层注意力原生适配超长序列，不再依赖外推算法

### V4对比V3全维度底层改动
1. **注意力机制范式替换**
   V3：MLA（维度压缩，所有token完整保留）
   V4：Hybrid CSA+HCA+SWA（序列块压缩，分层摘要远期文本）
2. 残差层结构重构：新增mHC流形约束，稳定超长序列深层梯度
3. 训练优化器替换：AdamW → Muon，训练收敛与数值稳定性大幅提升
4. MoE路由优化：预判式路由Anticipatory Routing，专家负载波动进一步降低
5. 数值精度工程：FP4索引器+FP8权重混合量化，超长KV缓存显存分层（GPU显存/磁盘分页）
6. 上下文能力质变：128K上限 → 原生1M token，不再依赖后训扩窗

# 迭代逻辑总结（清晰演进主线）
1. V1：验证自研稠密Transformer基线，摸清中英文大模型Scaling规律
2. V2：解决两大行业痛点——**训练太贵（MoE稀疏）、长文本显存爆炸（MLA）**，完成从稠密到MoE的底层切换
3. V3：精细化打磨MoE训练缺陷（负载均衡损失）、提升训练效率（MTP、FP8），最大化128K场景性能
4. V4：彻底重构长文本注意力体系，解决128K以上算力爆炸问题，同时修复深层超长序列训练不稳定（mHC、Muon），实现百万token原生推理
